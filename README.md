# SkillMaker

Unreal Engine 5.8 C++ 프로젝트입니다. 무기·애니메이션·발사체 목록을 조회하는 제작 UI, 스킬 데이터 편집·SaveGame 저장 코드, 캐릭터의 몽타주·발사체 실행 코드, 훈련장 UI 골격이 있습니다.

현재 코드는 `SkillMaker` 런타임 모듈 하나로 구성됩니다. 소스의 `UEEditor`와 문서의 제작 편집기는 게임 맵에서 HUD·UMG로 생성하는 화면을 가리킵니다. 별도 Unreal Editor 확장 모듈은 없습니다.

이 프로젝트는 같은 직업의 플레이어가 동일한 스킬을 사용하는 것이 당연하게 여겨지는 구조에 대한 의문에서 시작했습니다. 직업이 가능한 행동을 직접 금지하는 대신, 세계의 일관된 성질과 제약 안에서 플레이어가 자신의 능력과 전투 방식을 만들 수 있는지를 실험합니다. 자세한 배경은 [프로젝트의 출발점과 세계관 방향](Docs/PROJECT_VISION.md)에 정리했습니다.

문서의 기본 언어는 한국어이며, 코드·명령어·식별자·경로는 원문을 유지합니다.

## 코드에서 확인한 주요 흐름

- 리소스 조회: 선택 위젯 → `USKDataManagerSubsystem` → 무기·애니메이션·발사체 데이터 테이블.
- 저장: 제작 메인 위젯 → HUD의 스킬 데이터 → `USKSaveGameSubsystem` → `USKPlayerSkillSave` → 저장 슬롯.
- 프리뷰: 상세 위젯 → 제작 HUD → 프리뷰 캐릭터 → `USKSkillComponent` → 몽타주 → 이름이 일치하는 노티파이 → 발사체 생성.
- 훈련장: UI·슬롯 API가 있지만 스킬 선택·저장·장착을 잇는 주요 C++ 처리는 미완성입니다.

이 흐름은 함수와 호출 관계를 설명합니다. 편집값의 최종 저장 전달, 발사체의 피해·상태이상 적용, 쿨다운과 네트워크 처리에는 [알려진 문제](Docs/IMPLEMENTATION_STATUS.md)가 있으므로 전체 사용 흐름이 완료되었다는 의미는 아닙니다.

2026-09-05 기준 C++·설정 파일의 정적 검토를 반영했습니다. 블루프린트 내부, 맵별 월드 설정, 실제 플레이, 재시작 후 복원, 패키징 및 멀티플레이는 이번 문서 정리에서 검증하지 않았습니다. 프로젝트의 배경과 세계관 방향은 구현 현황과 분리해 기록하며, 세부 기능 설계는 확정하지 않았습니다.
